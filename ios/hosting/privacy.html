Política de Privacidade

Última atualização: julho de 2026

Esta política descreve como o aplicativo Verbalix trata os seus dados. Leia com atenção antes de utilizar o serviço.

O que é coletado e quando

O Verbalix não coleta dados em segundo plano. O texto que você deseja transformar só é enviado ao servidor quando você realiza uma ação explícita (toque em "Traduzir" ou "Melhorar"). Nenhuma outra informação é capturada automaticamente.

  • Endereço de e-mail: coletado no momento do cadastro para autenticação via link mágico. Utilizado exclusivamente para identificar a sua conta.
  • Texto enviado para transformação: enviado sob ação explícita do usuário à Edge Function própria do Verbalix (supabase/functions/transform), que repassa o texto à OpenAI para processamento. A chave da OpenAI nunca é exposta ao dispositivo.
  • Histórico de transformações: armazenado somente quando a opção "Salvar histórico" está ativada nas preferências. O histórico fica restrito à sua conta (política owner-only via RLS no banco de dados) e é excluído automaticamente após 30 dias. Se o histórico estiver desativado, nenhum texto transformado é persistido.

O que nunca é coletado

  • O texto selecionado não é registrado em logs de diagnóstico — este é um invariante verificado por testes automatizados no código-fonte (diagnostics.rs).
  • Senhas, dados de campos sensíveis ou histórico de digitação não são capturados pelo teclado personalizado.
  • Dados de localização, contatos ou arquivos do dispositivo não são acessados.

Teclado com Acesso Total

O teclado personalizado do Verbalix solicita Acesso Total (Full Access) exclusivamente para permitir o envio de texto à Edge Function via rede. Sem acesso à rede, a funcionalidade de tradução e melhoria de texto não pode ser executada a partir do teclado. O teclado não registra nem armazena o que é digitado.

Compartilhamento de dados

O texto enviado para transformação trafega pela infraestrutura do Supabase (banco de dados e Edge Functions) e é repassado à OpenAI para geração da resposta. Não compartilhamos seus dados com nenhum outro terceiro.

A OpenAI trata os dados conforme a política de privacidade da OpenAI.

Como excluir seus dados

  • Histórico: exclua os itens individualmente pelo app. O histórico expira automaticamente em 30 dias.
  • Exclusão de conta: entre em contato pelo e-mail abaixo solicitando a exclusão completa dos seus dados. Removemos a conta e todos os dados associados em até 30 dias úteis.

Segurança

A autenticação utiliza links mágicos com fluxo PKCE. Tokens de sessão são armazenados no Keychain do dispositivo. A comunicação entre o app e o servidor ocorre exclusivamente via HTTPS.

Alterações nesta política

Alterações significativas serão comunicadas por e-mail ou notificação no app. O uso continuado do serviço após a publicação de uma nova versão implica aceitação das mudanças.
